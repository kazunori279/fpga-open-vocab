# Not measured, and the two instruments that cannot measure it

The count row of [#23](https://github.com/kazunori279/fpga-open-vocab/issues/23)'s
envelope map — `three books` against `one book` — staged on 2026-08-21 and still
only a `queries.txt`. The other three rows are done; this one is open because
neither cheap instrument reaches it.

**`tools/synth_pairs.py` cannot.** Every instruction it sends ends in *"the same
objects around it, and the same physical object at the same position and the
same size in the frame"*, and that clause is why its pairs are readable rather
than re-composed scenes. Adding two books is exactly what it forbids. Dropping
the clause for one set would make that set's failures uninterpretable against
the other ten.

**`tools/mirror_pairs.py` cannot.** A mirror image holds the count fixed; that
is the property that made it the right tool for position.

What would work is selection rather than editing: val2017 photographs COCO
annotates with exactly one instance of a category against photographs it
annotates with exactly three. That is free and needs no generator, but the two
sides then come from different photographs, so anything correlated with count —
a library shelf against a hand holding a paperback — separates the set without
the encoder ever counting. Whoever picks this up has to answer that first,
because a positive result under that confound would mean nothing.

Shooting it by hand on one desk is the honest fallback and costs a morning.
