# Slide image sources

Retrieved 2026-11-14. These are official product images used to identify the
hardware, not photographs of the project's assembled measurement setup.
The images remain unchanged and retain their original proportions.

| Local file | Image credit and source page | Original image |
| --- | --- | --- |
| `forgix-board.png` | [Forgix / Adiuvo](https://forgix.tech/) | [Forgix board with coin](https://forgix.tech/wp-content/uploads/2026/08/Forgix-board-coin-002.png) |
| `logitech-streamcam.png` | [Logitech StreamCam](https://www.logitech.com/en-us/shop/p/streamcam.960-001286) | [StreamCam graphite product image](https://resource.logitech.com/content/dam/logitech/en/products/webcams/streamcam/gallery/streamcam-gallery-1-graphite.png) |

The product images belong to their respective owners and are not covered by
this repository's Apache-2.0 license.

`host/meter_cam.py` identifies StreamCam as the webcam used to record the USB
current-meter display. It is separate from the ArduCam Mega that supplies
images to the board's inference pipeline. The slides explain this distinction
and link the original source pages beside the images.

The Pages workflow copies both PNG files to `slides/assets/` in the published
site. The optional speaker photo `me.jpg` is separate and not published by this
workflow.
