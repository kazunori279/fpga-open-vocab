# Candidate wordings for the open-hand / closed-hand bench, for
# tools/probe_prompts.py. Scene A is the open hand, scene B the closed one, so
# a line meant to detect the closed hand should come back with a NEGATIVE d.
#
# THE HYPOTHESIS THIS LIST IS BUILT AROUND. Three runs now - a book, a glass, a
# hand - have ended the same way: the absence side ranks correctly across the
# two scenes but never wins its own, and in the last hand run "a closed hand"
# fired 0/90 and sat negative in both. SigLIP 2 fixed which way negation points
# without making the negated thing detectable, and the room calibration gave
# the positive side an 8x tighter spread while giving the complement nothing.
#
# So the move under test is not a better negation. It is to stop asking for
# one. English has a positive noun for the closed hand - fist - and none of
# these runs has ever used it. If "a fist" separates the two scenes where "a
# closed hand" does not, the wall was never about negation reading; it was
# about asking for the absence of a thing instead of for a thing.
#
# Everything else here is a control for that. The synonym block says whether
# any gain belongs to `fist` specifically or to changing the words at all; the
# template block says whether TEMPLATES' seven prompts already cover the "a
# photo of" framing, which they should; the parts block asks whether the
# separable visual evidence is the fingers rather than the hand.
